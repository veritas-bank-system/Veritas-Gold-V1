# Application AI Integration Telemetry

> Applies only to output produced by AI integrations implemented by this project. Antigravity assistant preference: **GPT-6 Luna** when available in the model picker. Never misreport assistant output as NVIDIA-generated.

Every response or artifact generated by the project's NVIDIA AI integrations MUST display the **Telemetry Status Header / Banner** containing. This does not apply to Antigravity's built-in assistant responses:
1. **Active NVIDIA Engine**: Specific model identifier (e.g. `nvidia/nemotron-3-super-120b-a12b:free` / `nvidia/nemotron-3-ultra-550b-a55b:free`).
2. **Provider**: `NVIDIA Integrate API / OpenRouter AI Gateway`.
3. **Session Telemetry**:
   - Estimated Tokens (Prompt + Completion).
   - Cumulative Request Turn Index.

### Format Standard:
`⚡ NVIDIA Engine Active: <Model Name> | Provider: <NVIDIA Integrate API / OpenRouter AI Gateway> | Request: #<Turn> | Tokens: ~<Prompt+Completion> tokens`
