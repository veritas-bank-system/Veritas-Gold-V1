# Application AI Integration Policy: NVIDIA Only

> **Scope:** These restrictions apply to AI functionality, APIs, and agents implemented or invoked by this application. They do not choose or restrict the built-in Antigravity assistant model. For Antigravity, prefer **GPT-6 Luna** when available in the model picker.

## 🚫 ZERO-TOLERANCE BANNED ENGINES & TOOLS
- **PERMANENTLY BANNED**: All Gemini, OpenAI, Claude, Anthropic, Mistral, Meta/Llama (un-fine-tuned), and all generic third-party AI APIs or models.
- No direct external AI API calls may bypass the `ai-gateway` MCP server.

## ⚡ MANDATORY EXCLUSIVE MCP SERVER & ROUTING
All AI inference, code generation, refactoring, planning, embeddings, and reranking performed by application integrations or project-owned agents **MUST EXCLUSIVELY** use the `/nvidia-mcp` MCP server (`ai-gateway`) via `/nvidia-ai` workload routing. This does not govern Antigravity's built-in assistant model selection.

### 🛠️ MCP Tools (`/nvidia-mcp`):
1. **`query_openrouter`**: Restricted strictly to verified NVIDIA Nemotron models.
2. **`query_nvidia_nim`**: Direct NVIDIA Integrate API with automatic fallback to OpenRouter AI Gateway.
3. **`generate_nemotron_embedding`**: Text and multimodal embeddings via `nvidia/nemotron-3-embed-1b:free` or `nvidia/llama-nemotron-embed-vl-1b-v2:free`.
4. **`rerank_nemotron`**: Document and visual cross-encoder reranking via `nvidia/llama-nemotron-rerank-vl-1b-v2:free`.

### 🎯 Dynamic Workload Routing (`/nvidia-ai`):
Every AI request must route to the optimal NVIDIA Nemotron model:
- **Architecture, Deep Planning & System Refactoring**: `nvidia/nemotron-3-ultra-550b-a55b:free` (550B MoE, 1M context)
- **Core Software Engineering, Logic & Rust Implementation**: `nvidia/nemotron-3-super-120b-a12b:free` (120B MoE, 1M context)
- **High-Speed Iterations, Scripts & Boilerplate**: `nvidia/nemotron-3.5-lightning:free` (30B MoE)
- **Multimodal, Visual UI & Extended Step-by-Step Reasoning**: `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free` (30B-A3B MoE)
- **Embeddings & Semantic Search**: `nvidia/nemotron-3-embed-1b:free`
- **Multimodal Reranking & Verification**: `nvidia/llama-nemotron-rerank-vl-1b-v2:free`

## 🛰️ MANDATORY TELEMETRY HEADER
Responses or artifacts generated by the application's NVIDIA AI integrations MUST begin with the following. Do not use this banner to misidentify Antigravity assistant output:
`⚡ NVIDIA Engine Active: <Model Name> | Provider: OpenRouter AI Gateway | Request: #<Turn> | Tokens: ~<Prompt+Completion> tokens`
