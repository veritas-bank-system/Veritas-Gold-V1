# DFINITY Internet Computer (ICP) Skills Suite (/icskills)

Official skills for high-assurance Internet Computer (ICP) architecture, Motoko, and Rust canister development.

## Core Canister Architecture & Security:
- **Canister Security**: `canister-security` (Access control, anonymous caller protection, inter-canister call guards)
- **Stable Memory**: `stable-memory` (Orthogonal persistence, ic-stable-structures, zero-serialization upgrades)
- **Real-World APIs**: `https-outcalls` (Consensus-verified HTTPS requests with transform functions)
- **Token Ledgers**: `icrc-ledger` (ICRC-1, ICRC-2, ICRC-3 standard implementations)
- **Cryptography**: `vetkeys` (Verifiably Encrypted Threshold Keys, private key derivation on-chain)
- **Authentication**: `internet-identity` and `agent-web-identity`
- **EVM Integration**: `evm-rpc` (Querying and submitting transactions to Ethereum/EVM chains)
- **Cycles & Infrastructure**: `cycles-management`, `multi-canister`, `sns-launch`
