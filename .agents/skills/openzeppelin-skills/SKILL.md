# OpenZeppelin Smart Contract Skills Suite (/openzeppelin-skills)

Use this skill suite for developing, auditing, securing, and upgrading production-grade smart contracts across major ecosystems.

## Available Modules:
1. **Solidity Security & Development**: `develop-secure-contracts`, `setup-solidity-contracts`, `upgrade-solidity-contracts`
2. **Arbitrum Stylus (Rust)**: `setup-stylus-contracts`, `upgrade-stylus-contracts`
3. **Starknet Cairo**: `setup-cairo-contracts`, `upgrade-cairo-contracts`
4. **Sui Move**: `setup-sui-contracts`, `review-sui-contracts`
5. **Stellar Soroban**: `setup-stellar-contracts`, `upgrade-stellar-contracts`

All development strictly incorporates OpenZeppelin battle-tested security standards: reentrancy guards, role-based access control, safe arithmetic, and formal verification.
